# Датасет для вендорского конвейера

Источник: `dumps/dataset/*.npz`, ключ `frames`, форма `(N, 4, 5120)` uint16 + JSON-метаданные
(base/down hex, FDT-маски).
- 5120 = 80 строк × 64 столбца (W=64 быстрый индекс), значения ~350..3350 — сырые 12-битные отсчёты.
- 4 кадра на касание: **0 = фон**, **2 = полный контакт**, 1 и 3 — промежуточные фазы.
- Наборы: `natural` 30, `genuine` 25 (в отчётах «varied»: разные углы до 90°+ и участки),
  `impostor` — два файла (10 и 100), `load()` берёт последний ⇒ в экспорте 100.

Экспорт для C: `tools/algo/export_raw.py` → `frames_raw.bin` (кадр 2), `bg_raw.bin` (кадр 0),
`meta_raw.txt` (`метка индекс`), 155 записей, uint16 LE в исходной раскладке 80×64.
Транспонирование в 64×80 делает сам `algo_eval4.c` (`transpose16`).

`frames.bin` / `proc8*.bin` — наш 8-битный `process(bg, frame)` (clip(bg − frame) + растяжка по перцентилям 1/99, инверсия)
(зеркало `process_frame()` из goodix5125.c). Для вендорского алгоритма **не годится**:
ему нужны сырые u16 через вендорский `preprocessor` (10).
